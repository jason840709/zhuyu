# 逐語使用說明

逐語是 Mac 的即時逐字稿：左右兩側各選繁體中文、英文或日文，App 會自動判斷講的是哪一種，原話放在它那一側，再翻成另一側的語言。需要 Apple Silicon、macOS 26 以上；收音來源可選麥克風或電腦播放的聲音。

## 開始使用

1. 打開 `逐語.app`。
2. 打開「設定」，選服務商，貼上 API 金鑰後按「儲存」。可以按「測試連線」確認金鑰；測試只讀取模型清單，不送出逐字稿。
3. 分別選擇語音辨識和翻譯要用哪一家，可以交叉搭配。OpenAI、Gemini 可以辨識語音；Claude 只做文字翻譯。
4. 按模型旁的「更換模型…」可從雲端清單挑模型並查看費率；也可在「手動輸入模型名稱」直接填。
5. 在逐字稿兩欄頂端選語言，底部選收音來源，按「開始辨識」（⌘R）。例如左邊英文、右邊繁中：講中文時原文在右、英文譯文在左；講英文則相反。

使用麥克風需要麥克風權限；收電腦播放的聲音需要「螢幕與系統音訊錄製」權限。

## 斷句

使用 OpenAI 辨識時，由逐語自己判斷一句話何時結束：停頓超過設定長度就換下一句並送出翻譯。「設定 → 換句停頓」可選 0.5、0.8（預設）或 1.2 秒。環境底噪（冷氣、風扇、背景音樂）會自動估計，不用調整。另外有幾條保險：

- 已經有文字、但 3 秒沒有新字時也會換句。
- 一句超過 12 秒時，會在下一個短暫換氣處切開；25 秒一定切開。
- 句子停在 "the"、"因為" 這類不可能是句尾的詞時，會多等一下再換句。

沒有人講話時，聲音不會送出，所以安靜的時間不計辨識費用。Gemini 由服務端自己斷句，不受這個設定影響。

## 暫譯與正式譯文

- **灰字是暫譯**：講話當下由本機引擎翻出的大意，會轉成台灣用語，但不潤飾。引擎可以在「設定 → 本機暫譯」更換或關閉，見 [替換本機暫譯引擎](替換本機暫譯引擎.md)。
- **黑字是正式譯文**：整句講完後由雲端翻譯服務產生，會去掉結巴、重複和口頭禪，依意思譯成通順的句子，並參考前三句，讓被停頓切開的句子接得起來。明顯的誤聽會依上下文翻成原本的詞。
- 原文欄保留實際說出的話。講者停頓或講到一半改口的地方會標成逗號，翻譯時採用改口後的說法。
- 「設定 → 辨識 → 翻譯情境」可以寫場合與聽眾，例如「研究所課程，教授以英文講課」，翻譯會依此選用語。

## 語意環境：情境摘要與罕見詞

「設定 → 自動整理主題與詞彙」預設開啟，使用「翻譯與詞彙」選的服務和金鑰。第 3 句講完後整理第一次，之後每 8 句一次，兩次之間至少隔 60 秒；情境沒變時，間隔會加倍（最多 32 句），每小時最多 30 次。每次整理做三件事：

- **改寫情境摘要**：用一句話描述場合、誰對誰說、目前在談什麼。每次都重寫成一句新的，長度固定，不會越積越多。這句話會交給語音辨識當提示，也交給翻譯。
- **挑出罕見詞**：最多 12 個容易聽錯的專有名詞和術語，依上下文寫成正確拼法，每次整份替換。常見詞不收。
- **修正明顯聽錯的字**：上下文很清楚、讀音也相近時，直接改正逐字稿並重新翻譯。

以 `gpt-6-luna` 的實際用量估算，一小時的演講（約 300 句、45 分鐘有聲音）：語音辨識約 0.77 美元、翻譯約 0.04 美元、情境整理約 0.004 美元。

每場對話都從零開始。想每次都用的詞，請在側邊欄「語意環境」的詞彙庫裡釘選，或寫進「專業術語」。

## 對話與匯出

- 側邊欄就是歷史紀錄，上方可以搜尋標題、原文和譯文。在對話上按右鍵可重新命名、匯出 Markdown／TXT 或刪除。
- 每句左側顯示開始時間和說話長度；正在講的句子是淺藍底。
- 每句的選單可以編輯原文、重新翻譯、校正譯文，或分開複製原文和譯文。翻譯失敗時原文仍會保存，可以之後重試。
- 「無痕模式」開啟時不保存逐字稿，也不寫入詞彙庫。

快捷鍵：`⌘N` 新對話、`⌘R` 開始／停止、`⌘E` 匯出 Markdown、`⌘,` 設定、`⌘⇧H` 歷史。

## 本機資料

- 歷史紀錄和設定存放在 `~/Library/Application Support/app.zhuyu.mac/`。在設定的「本機資料」可用 Finder 開啟。
- 金鑰是其中 `Private/` 目錄內的**明文檔案**。分享逐字稿時請使用 App 的匯出功能。
- 避免同時開兩個逐語寫同一份資料。
- 用 `--demo` 參數啟動是展示模式：只顯示示範資料，不收音、不連 API、不保存歷史。
