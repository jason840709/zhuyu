# 替換本機暫譯引擎

逐語在講話當下顯示的灰色字叫「暫譯」：在這台 Mac 上快速翻出來的大意。句子講完後，你在設定裡選的雲端翻譯服務會給正式譯文，取代暫譯。所以暫譯引擎只要做到兩件事：夠快、在本機執行。

替換方法有三種，由簡單到進階。

## 方法一：換一個模型（不用改程式）

預設引擎會連到一個 **OpenAI 相容**的本機伺服器，呼叫它的 `/v1/chat/completions`。Ollama、LM Studio、llama.cpp server、mlx-lm server 都支援這個格式。

1. 在本機伺服器下載你想用的模型，例如：

   ```bash
   ollama pull translategemma:12b     # 同系列較大的版本，品質較好但較慢
   ollama pull qwen3:4b               # 一般聊天模型也能翻譯
   ```

2. 打開逐語的「設定 → 本機暫譯」，填入：
   - **伺服器**：Ollama 是 `http://127.0.0.1:11434/v1`，LM Studio 預設是 `http://127.0.0.1:1234/v1`。
   - **模型**：伺服器上顯示的模型名稱，例如 `translategemma:12b`。

3. 按「開始辨識」。連不到伺服器或找不到模型時，畫面上方會顯示原因；暫譯會先停用，正式譯文照常出現。

選模型的建議：

- 暫譯每 0.3 秒左右就會更新一次，模型太大會跟不上。16 GB 記憶體的 Mac 建議用 4B 以下的模型。
- 會「思考」的推理模型會把思考過程放在 `<think>…</think>` 裡，逐語會自動去掉，但思考本身會拖慢速度，最好關掉推理或選非推理模型。
- 位址只能是這台 Mac（`127.0.0.1`、`localhost`、`::1`），這是為了讓暫譯的文字不離開電腦，程式會拒絕其他位址。

### 想改提示詞

提示詞寫在 `Sources/LocalDraftTranslator.swift` 的 `LocalModelDraftEngine.prompt`，格式照 TranslateGemma 的模型說明撰寫，一般聊天模型也看得懂。你偏好的模型如果需要別的指示，改這一段就好，改完重新執行 `bash build.sh`。

## 方法二：改用 Apple 系統翻譯

「設定 → 本機暫譯 → 引擎」選「Apple 系統翻譯」。這會用 macOS 內建的離線翻譯，不需要安裝其他軟體，但要先在「系統設定 → 一般 → 語言與地區 → 翻譯語言」下載對應的語言包（例如英文、中文（繁體））。

## 方法三：自己寫一個引擎

想接 Core ML、MLX、whisper.cpp 之類的其他執行方式，可以自己寫一個引擎。

1. 寫一個符合 `DraftTranslationEngine` 的型別。語言代碼會是 `"en"`、`"zh-TW"`、`"ja"`：

   ```swift
   struct MyDraftEngine: DraftTranslationEngine {
       func prepare(from source: String, to target: String) async throws {
           // 開始收音時呼叫一次。模型沒載入或缺檔時丟出錯誤，畫面會顯示錯誤訊息。
       }
       func translate(_ text: String, from source: String, to target: String) async throws -> String {
           // 回傳譯文。輸出簡體中文也沒關係，逐語會轉成繁體並換成台灣用語。
           return text
       }
   }
   ```

2. 在 `DraftEngineKind` 加一個選項，並在 `title` 裡寫上它在設定畫面顯示的名稱。

3. 在 `DraftEngineConfig.makeEngine()` 裡回傳你的引擎。

4. 執行 `bash verify.sh` 跑測試，再執行 `bash build.sh` 建置。

注意事項：

- 逐語一次只送一個暫譯請求：翻譯還沒回來時，期間的新文字只保留最新一筆，等上一筆完成再送。引擎仍要符合 Swift 6 的 `Sendable` 規則，編譯時會檢查。
- 一句話講到一半就會開始翻譯，所以輸入常常是不完整的句子。
- 逐語只顯示比上一次更長的暫譯，避免文字跳動。

## 測試你的本機伺服器

伺服器開著時，可以讓測試程式實際翻一句看看：

```bash
ZHUYU_DRAFT_ENDPOINT=http://127.0.0.1:11434/v1 ZHUYU_DRAFT_MODEL=translategemma:4b bash verify.sh
```

輸出會有一行「本機模型回覆：…」，最後顯示 `ALL PASS` 就表示可以用。
