查證日期：2026-11-17。以下為選單顯示的官方標準美元費率，語音辨識與文字翻譯分開計費。免費額度、快取折扣、批次折扣、稅金與帳戶特殊合約未算入。

模型先由服務商的模型清單 API 取得，再按用途顯示推薦模型與目前選擇。文字翻譯可勾選「其他可用文字模型」，列出該轉接介面支援的其他雲端文字模型。帳戶沒有返回的推薦模型不會憑空加入；未收錄的型號與快照不套用其他型號的價格。

## 連線與可用性

「儲存金鑰」只保存到本機，不連網；「測試連線」會呼叫模型清單 API，不送出逐字稿。連線成功代表金鑰可讀取清單，不保證每個模型都有推論額度或音訊權限。這些限制會在實際使用時顯示錯誤。

作者實際使用過 OpenAI 的辨識與 `gpt-6-luna` 翻譯；Gemini 與 Claude 只做過協定測試。
